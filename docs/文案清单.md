# DSH 安装器 — 全部界面文案

这份文件由脚本从源码里抽出来,方便统一改文案。

- **A 段**是词典,中英成对,改这里最省事(带 key,程序按 key 取)。
- **B 段**是散在各页里的内联文案,也是中英成对。
- **C 段**是 XAML 里写死的文案(多数是按钮/占位,运行时会被代码覆盖,列出来备查)。
- **D 段**是组件检测结果里的名称与说明(共享库里,会显示在列表行上)。
