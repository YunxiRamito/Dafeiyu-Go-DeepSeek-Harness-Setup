## 3. 下载中的细节行

格式：`阶段 · 速度 · 已下 / 总量`

```
下载中 · 1.2 MB/s · 8.2 MB / 34.0 MB
Downloading · 1.2 MB/s · 8.2 MB / 34.0 MB
```

速度取不到时显示 `--`。**这一行是刻意留的**：下载几十上百 MB 时总进度条走得慢，
用户真正要知道的是"在动吗、多快、还剩多少"。

> `BuiltInSteps.DescribeDownload()`

## 待确认的几处

1. `测速 ghproxy.net …` 和 `最快的是 …` 这类**带域名**的提示，域名要不要换成更友好的说法（比如"镜像 1"）？现在是直接露域名。
2. `分 8 条连接并行下载(10.4 MB)` —— "8 条连接"对普通用户是不是太技术了？可以改成 `正在加速下载(10.4 MB)`。
3. `下载停滞(连续 10 秒无数据)` —— 这句只会进日志，界面显示的是 `连接超时,正在切换下载源…`，确认一下是否可接受。
4. 引导窗口那句总体耗时说明 `安装程序需要先补齐必需的运行库,这一步可能需要几分钟。` —— 只在**缺运行库**时才准；运行库都齐时不缺这个阶段，但这句话仍会显示，要不要按情况换文案。
